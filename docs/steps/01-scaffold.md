# Step 01: Scaffold

**Branch:** `step/01-scaffold` (from `main`)

## Draft
- Goal: an empty app that builds, typechecks and runs tests. Spec: §Tech stack.
- Vite + React 19 + TypeScript (strict), Vitest (node env), `npm` scripts from CLAUDE.md.
- Tauri 2 skeleton in `src-tauri/` with the dialog and fs plugins only; window 1400×900; `.msi` bundle target.
- `src/platform`: the `Platform` interface (open/save file, open/save project folder, re-save to a remembered target for Save and Export Again) with web and Tauri implementations, picked at runtime.
- App icon generated by `scripts/make-icon.mjs` (an original 2×2 tile mark) and run through `tauri icon`.

## Check
- Creed: nothing here touches art. ✅
- Dependencies are the ones the spec lists (React, fflate, Tauri) plus `flexlayout-react` for the docking panels the spec asks for.
- Web fallback: the spec targets Windows/Tauri, but a browser build lets the app be developed and tested without Rust. The platform layer keeps this isolated.

## Built
- As drafted. The web platform uses the File System Access API (Chromium) and falls back to file input and downloads; project folders fall back to a `.zip`. Saving into a folder prunes stale files only inside subfolders the app writes (e.g. `tiles/`), never anything else.

## Verified
- `npm run typecheck`, `npm test` (smoke test) and `npm run build` pass.
- **Not verified:** `npm run tauri dev/build`. Rust isn't installed on this machine, so the Rust shell and `src/platform/tauri.ts` haven't been compiled or run.
